# Changelog

All notable changes to `Modified Date Control` will be documented in this file.

## v1.2.0

- Require PHP 8.3 or higher and test against PHP 8.3, 8.4, and 8.5.
- Allow `alleyinteractive/wp-type-extensions` `^5.0`.
- Tested up to WordPress 7.1.
- Update build tooling and dependencies.

## v1.1.1

- Bump `alleyinteractive/wp-type-extensions` to `^3.0 || ^4.0`.

## v1.1.0

- Bump `alleyinteractive/wp-type-extensions` to `^3.0`.

## v1.0.1

- Fix issue with the plugin not persisting modified dates.
- Fix issue with display of modified date.

## v1.0.0

- Initial release
